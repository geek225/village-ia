# Direction artistique

`maquette-reference.png` est l'image de référence retenue pour le projet. Le décor et les avatars de l'application React sont redessinés en SVG dans `src/App.tsx` afin de pouvoir animer les personnages indépendamment du paysage.

Les prochaines intégrations pourront remplacer les étapes temporisées de démonstration par des événements envoyés par le backend : mission reçue, consultation du routeur de modèles, agent sélectionné, traitement démarré, résultat disponible ou erreur.
